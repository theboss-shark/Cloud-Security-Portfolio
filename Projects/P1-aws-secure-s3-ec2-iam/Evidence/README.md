

# Security Evidence and Screenshots

This directory contains screenshots documenting the implementation and validation of the Secure EC2-to-S3 Access project.

## Evidence Categories

1. EC2 instance configuration.
2. S3 bucket security settings.
3. IAM role and permissions policy.
4. AWS STS identity verification.
5. Successful S3 listing, upload, and download operations.
6. Denied unauthorized object deletion.
7. CloudTrail S3 data events, when verified.

## Evidence Standards

Each screenshot should demonstrate a specific configuration or test result. Screenshots must reflect actual observed behavior and must not expose credentials, session tokens, private keys, or unnecessary account and network details.

See `../Tests/validation.md` for the corresponding test outcomes.
